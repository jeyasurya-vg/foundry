Part 6: "Skills and plugins. Never auto-load. Explicit allowlist. Every third-party skill
gets: a source URL, a pinned commit, a recorded permission surface, and a periodic integrity
re-check." This is that inventory — currently two entries, both reviewed and vendored by
hand, not generated by the (not-yet-built) `librarian` pipeline.

Full provenance for each (exact commit, license copyright line, content-scan result, scope
notes) is in that skill's own `MANIFEST.json`, matching the schema the addendum defines for
`librarian`-generated skills (Part 10.4) — same shape whether a skill was generated or
vendored by hand.

## Why these two and not the others

A batch of other repos was evaluated for inclusion in the same pass and rejected — see
`docs/ROADMAP.md`'s skill-adjacent notes. The two here passed on the same bar every future
skill has to clear: real source URL, pinned commit, a human actually reading the content
(not just a summary) for injection/exfiltration/credential-harvesting patterns before it
touches this repo, and a stated reason it's relevant to what Foundry actually does.

## `taste-skill` does not fix Mission Control

Worth stating plainly since it's the reason this review happened at all: `taste-skill`'s own
frontmatter scopes it to "landing pages, portfolios, and redesigns" and its body says
outright it's "inappropriate for dashboards." It will not improve `shell/console` — Mission
Control's redesign was done by hand, informed by OpenClaw's and Hermes Agent's actual
Control UI patterns (persistent sidebar, status indicators, dense data density), not by this
skill. `taste-skill` is here for whenever Foundry (or a project built with it) needs a
marketing or portfolio page instead.

## Integrity re-check

Not automated yet — Part 8's "periodic integrity re-check" needs the skill inventory screen
in Mission Control (not built, see `docs/CONSOLE.md`) or a standalone script diffing the
vendored file against the source repo's current HEAD at the pinned commit. Two entries is
small enough to check by hand for now; automate before this list grows much further.
